# NotchBeat 0.3 — an activity center around your Mac’s notch

[Русский](README.md) | **English**

NotchBeat2 is my macOS project, developed with the help of OpenAI Codex. I defined the features and interface requirements, tested the app, and refined the changes. The code was generated by Codex.

A native Swift + SwiftUI + AppKit project for **macOS 15+**, built with Xcode 16+. Suitable for the 15″ MacBook Air M4: the app uses the physical notch geometry of the selected display. On displays without a notch, the island is a separate window with adjustable size and position.

The app currently uses Russian interface labels. English translations of those labels below are provided for reference.

## What’s new in 0.3

- Expand on hover: the default delay is **30 ms**, down from 180 ms, with **12 pt** of extra hover padding. Adjust these in “Остров → Взаимодействие” (Island → Interaction). A zero delay is supported. The padding only affects hover detection; clicks outside the visible shape pass through. Long presses work alongside regular buttons.
- Calendars: events from selected calendars for the next seven days appear in settings and the island. All-day events appear in the list but do not occupy the countdown slot for the next event. Expanding an event reveals its end time, calendar, location, and notes.
- A new **Reminders** module: system EventKit integration, list selection, incomplete and completed tasks, completion toggles, and task creation with or without a due date and time. The compact island counts overdue tasks and tasks due today. Future tasks and tasks without a due date remain available in the expanded list.
- A **“Показывать напоминания в островке”** (Show reminders in the island) toggle in “Настройки → Напоминания → Островок” (Settings → Reminders → Island). It is on by default and persists across restarts. Turning it off hides the reminder icon and task count while preserving the positions of other elements. Hidden reminders are excluded from the additional activity count. If no other activities are present, the collapsed island disappears completely; other modules continue to work.
- Fixed initial reminder list setup: if EventKit returns lists with a delay, automatic selection occurs on a subsequent refresh once the lists become available. Manually deselecting all lists after initialization is respected.
- Existing settings survive the addition of new fields. The new module is enabled after an upgrade, but data access requires permission. The recording module’s `finalize()` naming conflict remains fixed.

To connect Reminders, open **Настройки → Напоминания → Подключить системные Напоминания** (Settings → Reminders → Connect system Reminders). Manage access in System Settings → Privacy & Security → Reminders. All lists are selected on first connection; deselect any you do not need. Adding tasks and changing completion status modifies real reminders, including recurring tasks; your system account handles synchronization. Read-only lists cannot be modified. Alerts for new tasks with a due time are created as system alarm objects and depend on the Reminders app’s notification settings; NotchBeat does not duplicate them with its own local banner.

If tasks do not appear after connecting, check permission, whether the module is enabled, and the checkboxes under “Выбранные списки” (Selected lists). Then click **“Обновить”** (Refresh) under “Задачи” (Tasks). If lists are still unavailable, open the system Reminders app and refresh again. The module also polls every 30 seconds while enabled. To appear in the compact island, tasks must be incomplete and due today or overdue, and the visibility toggle must be on. Turning the toggle off keeps tasks accessible in settings and the expanded center.

## Running and updating

1. Extract the archive into a **new folder**. Keep the previous working version separately.
2. Open `NotchBeat.xcodeproj` and select the **NotchBeat → My Mac** scheme and destination.
3. Press **⌘R**. If signing is requested, select the NotchBeat target → Signing & Capabilities → **Sign to Run Locally**.
4. Select a display in settings. On first launch, the app explains notch emulation and available permissions.
5. For an initial music check, open desktop Spotify, play a track, click **“Подключить Spotify”** (Connect Spotify) in music settings, and allow control of Spotify.
6. If no music is available, use the island demo. It is clearly marked, lasts 15 seconds, and disables playback controls.

The bundle ID remains `com.alex.notchbeat`, and settings from version 0.1 are migrated. Run only one version of the app at a time. Closing settings does not quit the app. The Dock icon opens the center; the menu bar provides access to the center, settings, and Quit.

## Interface

An empty island collapses around the camera. If reminder visibility is off, the empty collapsed island is hidden completely. You can still open the center through the app menu or Dock icon. A single active module uses the leading and trailing regions. With two activities, two modules are displayed; the third gets a small side indicator, and additional activities are represented by a count. Priorities are configurable in settings; recording has a higher default priority than the timer and music.

Click to expand the selected module, or hover to expand the island when that option is enabled. The expanded view provides a center for all enabled modules, module tabs, the last hour of activity history, and settings. Open history with its button or a downward gesture in the header area. A long press opens quick actions. The expanded view collapses after the pointer leaves or the configured inactivity timeout expires. The system Reduce Motion setting disables spring transitions.

Size changes use a single SwiftUI spring animation inside a fixed transparent NSPanel; the window itself is not resized frame by frame. The clickable region follows the current animated geometry, and transparent areas let clicks pass through. Exact behavior at the island’s edges, in the menu bar, across Spaces, and in full screen requires manual testing.

The island stays black to blend into the camera notch; materials and accents adapt to the theme and album artwork. Spring parameters are approximate and do not guarantee a match with the iPhone’s proprietary animation behavior. The equalizer is decorative, music progress is informational, and seeking is not implemented.

## Built-in modules

| Module | Features |
|---|---|
| Music | Artwork, track, artist, progress, play/pause/next/previous; MediaRemote with a Spotify fallback |
| Pomodoro | 25/5, 50/10, custom presets; pause, session restoration, notifications; **breaks start only after confirmation** |
| Calendar | EventKit, **selection of specific calendars**, upcoming events, countdown, reminders a configurable number of minutes before an event |
| Reminders | System lists, tasks, completion, task creation, and a count of tasks due today or overdue |
| Battery | Actual internal battery state; brief activity when power is connected or disconnected |
| Downloads | HTTP/HTTPS downloads started in NotchBeat; destination selection, actual progress, pause/resume/cancel |
| AirDrop | File and recipient selection through the system sharing interface; opening AirDrop in Finder |
| Recording | Recording the selected screen with system audio to MP4, or recording the microphone separately to M4A |

**System integration limits:** the app does not track every download in Finder or browsers, provide its own controls for receiving AirDrop files, or monitor recordings started by other apps. macOS handles incoming AirDrop transfers. Recordings and downloads shown in the island are operations started in NotchBeat. These are limits of the current implementation, rather than features hidden by missing permissions.

Screen recording is limited to a width of 1920 pixels at 30 fps; a separate microphone track is not added to video recordings. Microphone recording supports pausing; screen recording supports stopping. “Пауза всех” (Pause all) does not stop screen recording, and the app explains this. On quit, an active recording is finalized with a limited wait for saving. For an important recording, stop it first and verify the file manually.

Disabling music or battery stops polling its source; disabling the calendar removes its reminders. The timer and downloads are paused and must be resumed manually after re-enabling. An AirDrop transfer already started through the system continues through macOS. An active recording remains accessible until stopped, even if its module is disabled.

## Permissions and data

Permissions are requested in response to user actions:

- **Spotify:** System Settings → Privacy & Security → Automation → NotchBeat → Spotify. The entry appears after the first connection attempt. Then try connecting again.
- **Calendar:** allow full access when connecting EventKit, then select the calendars you want. If access was denied, go to Privacy & Security → Calendars.
- **Reminders:** allow full access when connecting, then check the selected lists. If access was denied, go to Privacy & Security → Reminders. The island visibility toggle does not change system permission.
- **Screen:** when starting a recording, allow Screen & System Audio Recording in Privacy & Security. Restart the app if macOS requests it.
- **Microphone:** allow microphone access when starting a separate audio recording, or change access in the Microphone section.
- **Notifications:** requested when starting the timer or connecting the calendar. If denied, the timer still works but banners are not delivered. Change permission in System Settings → Notifications → NotchBeat.

Spotify does not require Accessibility permission: it uses Apple Events without simulating mouse input. AirDrop sending uses the system NSSharingService and does not require a separate AirDrop permission.

No OAuth, Spotify API, or application server is required. Fallback artwork is downloaded over HTTPS from Spotify URLs; downloads use URLs entered by the user. Calendar data is read locally, and recordings are saved to selected files. Settings and the timer session use UserDefaults; the island keeps the last hour of history in memory.

## Music and compatibility

The private MediaRemote framework is loaded dynamically, with symbol checks, timeouts, and reduced retry frequency. It may be restricted by the system or change after a macOS update. **Support for Apple Music, browsers, and other players on macOS 26.6.2 has not been verified and is not guaranteed.** `MPNowPlayingInfoCenter` is not used to read global playback information from other apps.

When MediaRemote is unavailable, a local AppleScript/JXA fallback is used for Spotify. A previous version working on your Mac does not mean a new version has already been verified. Bundle ID exclusions apply to the entire app; unknown sources are hidden when the exclusion list is nonempty. Individual browser tabs are not distinguished.

## Settings and installation

Settings include module switches, priorities, display selection, hover expansion, music pause and inactivity timeouts, emulated size and position, artwork accents, trackpad haptic feedback, and launch at login. Haptics require supported hardware. If the selected monitor is disconnected, the island is hidden; the app does not move it to another display automatically.

For everyday use: Products → NotchBeat.app → Show in Finder, copy it to **Applications**, launch it from there, and enable launch at login. This uses `SMAppService.mainApp`; confirmation may be required in Login Items. Do not move the `.app` after configuring launch at login.

Distribution requires Developer ID signing, notarization, and your own developer account. The project enables Hardened Runtime and disables the sandbox; using private MediaRemote APIs creates a risk of Mac App Store rejection. The archive does not include a notarized application binary.

## Project structure

- `NotchBeat/Core/IslandLogic.swift`: independent logic for sessions, priorities, history, and exclusions.
- `NotchBeat/Modules/IslandModule.swift`: the internal compact/expanded/minimal protocol and lifecycle.
- `NotchBeat/Modules/*Module.swift`: built-in modules.
- `NotchBeat/Media/`: private bridge, Spotify fallback, and playback controls.
- `NotchBeat/AppModel.swift`: activity and settings coordinator.
- `NotchBeat/UI/IslandView.swift`, `NotchBeat/UI/IslandWindowController.swift`: animation, NSPanel, and click-through behavior.
- `NotchBeat/UI/SettingsView.swift`: onboarding and settings.

Third-party modules cannot be added. There are no external Swift packages. The project and icon are already included; no generators are needed to open the project.
